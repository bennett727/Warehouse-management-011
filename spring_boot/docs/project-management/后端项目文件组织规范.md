# 后端项目文件组织规范

## 目录结构

```
spring_boot/
├── config/                 # 配置文件目录
│   ├── .env.example       # 环境变量示例文件
│   ├── .gitignore         # Git忽略配置
│   └── .gitattributes    # Git属性配置
├── docs/                 # 文档目录
│   ├── api/              # API文档
│   ├── architecture/     # 架构设计文档
│   ├── testing/          # 测试相关文档
│   └── *.md            # 其他文档
├── scripts/              # 脚本目录
│   ├── launch/           # 启动脚本
│   ├── sql/             # SQL脚本
│   └── tools/           # 工具脚本
├── src/                 # 源代码目录
│   ├── main/            # 主代码
│   │   ├── java/       # Java源代码
│   │   └── resources/  # 资源文件
│   └── test/           # 测试代码
│       ├── java/       # Java测试代码
│       └── resources/  # 测试资源文件
├── .env                 # 环境变量文件（本地配置，不提交到Git）
├── .gitignore           # Git忽略文件配置
├── pom.xml              # Maven项目配置
├── mvnw                 # Maven包装器（Unix/Linux）
├── mvnw.cmd             # Maven包装器（Windows）
└── README.md            # 项目说明文档
```

## 文件命名规范

### 1. 配置文件
- 环境变量：`.env`（本地）或`.env.example`（示例）
- Git配置：`.gitignore`, `.gitattributes`
- 应用配置：`application-{profile}.properties`

### 2. 脚本文件
- Windows批处理：`start.bat`, `deploy.bat`
- PowerShell脚本：`start.ps1`, `deploy.ps1`
- Shell脚本：`start.sh`, `deploy.sh`
- SQL脚本：`init_database.sql`, `init_default_admin.sql`
- Python脚本：`create_package_info.py`, `fix_code_style.py`

### 3. 文档文件
- 使用小写+下划线命名：`api_documentation.md`, `architecture_design.md`
- 中文文档使用中文命名：`测试日志分析报告.md`
- 英文文档使用英文命名：`API_DOCUMENTATION.md`

### 4. Java源代码
- 类名：PascalCase（首字母大写）：`UserService.java`
- 包名：小写+点分隔：`com.backend.service`
- 方法名：camelCase（动词开头）：`getUserById()`
- 变量名：camelCase：`userName`
- 常量名：全大写+下划线：`MAX_PAGE_SIZE`

### 5. 测试文件
- 单元测试：`{ClassName}Test.java`（如：`UserServiceTest.java`）
- 集成测试：`{ClassName}IntegrationTest.java`
- API测试：`test_{module}_api.js`（如：`test_device_api.js`）
- 端到端测试：`test_{feature}_e2e.js`

## 文件组织原则

### 1. 按功能分类
- API相关文件放在`tests/api/`
- 集成测试放在`tests/integration/`
- 模块测试放在`tests/modules/`

### 2. 按类型分类
- 配置文件放在`config/`
- 文档文件放在`docs/`
- 脚本文件放在`scripts/`

### 3. 按环境分类
- 开发环境配置：`application-dev.properties`
- 生产环境配置：`application-prod.properties`
- 测试环境配置：`application-test.properties`

## Git忽略规则

运行时生成的文件和目录应被Git忽略：
- `target/` - Maven构建输出
- `logs/` - 应用日志
- `.mvn/` - Maven包装器缓存
- `.env` - 本地环境变量

## 文档分类

### API文档
- 接口说明
- 请求/响应格式
- 错误码定义

### 架构文档
- 系统架构设计
- 模块设计说明
- 数据库设计

### 测试文档
- 测试用例说明
- 测试覆盖率报告
- 测试日志分析

### 运维文档
- 部署指南
- 运行手册
- 故障排查指南
