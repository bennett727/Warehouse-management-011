# 库存管理模块设计规范文档

## 1. 概述

### 1.1 设计目标
- 统一库存管理各模块的界面风格和交互逻辑
- 提升用户操作效率和体验
- 确保数据一致性和业务流程完整性

### 1.2 适用范围
- 入库管理
- 出库管理
- 库存调拨
- 库存盘点

## 2. 设计原则

### 2.1 一致性原则
- 统一的页面布局和视觉风格
- 统一的表单设计和验证规则
- 统一的操作反馈和提示信息

### 2.2 效率原则
- 减少用户操作步骤
- 提供批量操作功能
- 支持快捷导航和搜索

### 2.3 清晰性原则
- 信息层次分明
- 状态标识清晰
- 操作流程明确

## 4. 组件设计规范

### 4.1 操作型组件

#### 4.1.1 新建对话框 (CreateDialog)
**设计要点**:
- 采用上下分区布局
- 上半部分：单据基本信息（单号、日期、类型等）
- 下半部分：明细信息（设备选择、数量录入等）
- 支持分步操作（选择设备 → 录入详情）

**交互流程**:
1. 点击"新建"按钮打开对话框
2. 填写基本信息
3. 选择/添加明细设备
4. 录入设备详细信息
5. 提交保存

**表单验证**:
- 必填字段实时验证
- 数量范围验证
- 库存可用性验证

#### 4.1.2 编辑对话框 (EditDialog)
**设计要点**:
- 继承新建对话框布局
- 预填充现有数据
- 支持增删改明细项

#### 4.1.3 审核对话框 (AuditDialog)
**设计要点**:
- 简洁的审核结果选择
- 审核意见输入
- 操作确认机制

### 4.2 展示型组件

#### 4.2.1 数据表格 (DataTable)
**设计要点**:
- 固定表头，支持滚动
- 操作列固定右侧
- 状态列使用Tag标识
- 支持排序和筛选

**列设计规范**:
| 列类型 | 宽度 | 对齐 | 说明 |
|--------|------|------|------|
| 单号 | 180px | 左对齐 | 唯一标识 |

| 数量 | 100px | 居中 | 数字格式 |
| 操作 | 280px | 左对齐 | 按钮组 |

#### 4.2.2 筛选栏 (FilterBar)
**设计要点**:
- 折叠/展开功能
- 常用条件快速筛选

#### 4.2.3 详情展示 (DetailView)
**设计要点**:

## 5. 业务流程规范

### 5.1 入库管理流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  创建   │ → │  编辑   │ → │  提交   │ → │  审核   │ → │  执行   │
│  (草稿) │    │  (草稿) │    │  (待审) │    │  (通过) │    │  (完成) │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
     ↓              ↓              ↓              ↓              ↓
  新建入库单    修改信息      提交审核      审核通过      入库执行
  填写基础      添加明细      状态变更      生成入库      更新库存
  信息          保存草稿      待审核        记录          状态更新
```

**状态定义**:
- 0: 草稿 - 可编辑、删除、提交
- 1: 待审核 - 可审核
- 2: 已通过 - 可执行入库
- 3: 已完成 - 只读
- 4: 已拒绝 - 可重新编辑

### 5.2 出库管理流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  创建   │ → │  编辑   │ → │  提交   │ → │  审核   │ → │  执行   │
│  (草稿) │    │  (草稿) │    │  (待审) │    │  (通过) │    │  (完成) │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
     ↓              ↓              ↓              ↓              ↓
  新建出库单    修改信息      提交审核      审核通过      出库执行
  选择出库      添加设备      状态变更      生成出库      更新库存
  类型          录入详情      待审核        记录          创建关联单
```

**出库类型**:
- 0: 普通出库
- 1: 安装出库 → 自动创建安装记录
- 2: 维修出库 → 自动创建维修记录
- 3: 报废出库 → 自动创建设备报废记录

### 5.3 库存调拨流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  创建   │ → │  审核   │ → │  出库   │ → │  入库   │
│  调拨单 │    │  调拨单 │    │  执行   │    │  确认   │
└─────────┘    └─────────┘    └─────────┘    └─────────┘
     ↓              ↓              ↓              ↓
  选择调出      审核调拨      调出仓库      调入仓库
  调入仓库      合理性        扣减库存      增加库存
  选择设备
```

### 5.4 库存盘点流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  创建   │ → │  执行   │ → │  差异   │ → │  调整   │
│  盘点计划│    │  盘点   │    │  分析   │    │  确认   │
└─────────┘    └─────────┘    └─────────┘    └─────────┘
     ↓              ↓              ↓              ↓
  选择盘点      扫描/录入     系统库存      审核差异
  范围          实际数量      vs实盘        更新库存
```

## 7. 交互规范

### 7.1 表单交互

#### 输入验证
- 实时验证：输入时即时反馈
- 失焦验证：离开字段时验证
- 提交验证：提交前统一验证

#### 错误提示
- 在字段下方显示错误信息
- 使用红色边框标识错误字段
- 提供明确的错误说明

### 7.2 表格交互

#### 行操作
- 悬停显示操作按钮
- 点击行可查看详情
- 支持批量选择操作

#### 分页交互
- 默认每页10条
- 支持页码跳转
- 显示总记录数

### 7.3 对话框交互

#### 打开/关闭
- 打开时有遮罩层
- 点击遮罩可关闭（可配置）
- ESC键可关闭

#### 数据保存
- 关闭前提示未保存数据
- 提供"保存草稿"选项
- 确认后关闭

## 10. 实现示例

### 10.1 新建出库单对话框使用示例

```vue
<template>
  <OutboundOrderDialog
    v-model="dialogVisible"
    :mode="dialogMode"
    :initial-data="currentRow"
    @confirm="handleConfirm"
    @cancel="handleCancel"
  />
</template>

<script setup>
import { ref } from 'vue';
import OutboundOrderDialog from '@/components/business/dialogs/OutboundOrderDialog.vue';
import { createOutboundOrder, updateOutboundOrder } from '@/api/inventory/outbound';

const dialogVisible = ref(false);
const dialogMode = ref('create');
const currentRow = ref({});

// 打开新建对话框
const handleCreate = () => {
  dialogMode.value = 'create';
  currentRow.value = {};
  dialogVisible.value = true;
};

// 打开编辑对话框
const handleEdit = (row) => {
  dialogMode.value = 'edit';
  currentRow.value = { ...row };
  dialogVisible.value = true;
};

// 确认提交
const handleConfirm = async (formData) => {
  try {
    if (dialogMode.value === 'create') {
      await createOutboundOrder(formData);
    } else {
      await updateOutboundOrder(currentRow.value.id, formData);
    }
    ElMessage.success('保存成功');
    loadData();
  } catch (error) {
    console.error('保存失败:', error);
  }
};
</script>
```
