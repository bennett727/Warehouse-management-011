# 组件整合优化方案

## 问题概述

重构后发现存在多处组件重复和功能重叠问题，需要进行整合优化。

## 重复组件清单

### 1. 设备选择器组件（优先级：高）

#### 现状
- `src/components/business/dialogs/DeviceSelector.vue` - 业务模块设备选择器
- `src/components/device/DeviceSelector.vue` - 新建设备选择器

#### 差异对比
| 特性 | business/dialogs版本 | device版本 |
|-----|---------------------|-----------|
| 用途 | 向导式流程中的设备选择 | 通用设备选择 |
| 筛选功能 | 设备类型、状态筛选 | 设备类型筛选 |
| 显示字段 | 设备编号、名称、类型、规格、可用库存、位置 | 设备编号、名称、类型、规格、库存数量、仓库 |
| 已选展示 | 顶部Tag展示 | 底部Tag展示 |
| 操作按钮 | 无（由父组件控制） | 取消/确定按钮 |

#### 整合方案
**推荐保留**：`src/components/device/DeviceSelector.vue`

**理由**：
1. 通用性更强，可作为基础组件使用
2. 代码结构更清晰，有完整的分页和已选展示
3. 可通过props控制是否显示操作按钮

**操作步骤**：
1. 删除 `src/components/business/dialogs/DeviceSelector.vue`
2. 更新引用该组件的文件（如 OutboundCreationWizard.vue）
3. 增强 device/DeviceSelector.vue 的功能：
   - 添加 `showActions` prop 控制是否显示操作按钮
   - 添加 `showStatusFilter` prop 控制是否显示状态筛选

#### 代码修改示例
```vue
<!-- DeviceSelector.vue 增强 -->
<script setup>
const props = defineProps({
  showActions: {
    type: Boolean,
    default: true
  },
  showStatusFilter: {
    type: Boolean,
    default: false
  },
  // ...其他props
});
</script>

<template>
  <!-- 条件渲染操作按钮 -->
  <div v-if="showActions" class="selector-actions">
    <el-button @click="handleCancel">取消</el-button>
    <el-button type="primary" @click="handleConfirm">确定</el-button>
  </div>
</template>
```

### 2. 业务审批/记录组件（优先级：中）

#### 现状
- `src/components/business/BusinessApproval.vue` - 审批列表组件
- `src/components/business/BusinessRecords.vue` - 记录列表组件
- `src/views/business-management/BusinessManagementPage.vue` - 整合页面

#### 分析
新创建的 BusinessManagementPage.vue 已经包含了这两个组件的核心功能：
- 业务记录表格展示
- 业务审批表格展示
- 模式切换
- 筛选功能

#### 整合方案
**方案A：保留独立组件（推荐）**
- 保留 BusinessApproval.vue 和 BusinessRecords.vue
- 将 BusinessManagementPage.vue 重构为使用这两个子组件
- 优点：职责分离，便于单独使用

**方案B：删除独立组件**
- 删除 BusinessApproval.vue 和 BusinessRecords.vue
- 仅在 BusinessManagementPage.vue 中实现功能
- 优点：减少文件数量

**推荐方案A**，因为独立组件可能在其他场景复用。

#### 重构 BusinessManagementPage.vue
```vue
<template>
  <PageLayout title="业务管理">
    <!-- 模式切换 -->
    <ModeSwitcher v-model="currentMode" />
    
    <!-- 业务记录模式 -->
    <BusinessRecords 
      v-if="currentMode === 'records'"
      :data="recordData"
      @view="handleView"
      @edit="handleEdit"
    />
    
    <!-- 业务审批模式 -->
    <BusinessApproval
      v-else
      :data="approvalData"
      @approve="handleApprove"
      @reject="handleReject"
    />
  </PageLayout>
</template>
```

1. **功能丢失风险**：删除组件前确保新组件包含所有必要功能

3. **样式差异风险**：不同组件可能有不同的样式，整合时注意统一
4. **数据格式风险**：确保组件间的数据格式兼容
