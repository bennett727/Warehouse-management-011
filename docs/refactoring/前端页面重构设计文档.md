# 前端页面系统性重构设计文档

## 概述

本次重构针对仓库管理系统(WMS)的前端页面进行系统性改进，主要包含两个核心模块的重构：

1. **业务记录模块与业务审批模块整合**
2. **出库管理页面导向式流程重构**

## 重构内容

### 1. 业务记录与审批整合设计

#### 1.1 新增文件

| 文件路径 | 说明 |
|---------|------|
| `src/views/business-management/BusinessManagementPage.vue` | 业务管理统一页面，整合记录与审批功能 |
| `src/api/business/approval.js` | 业务审批API模块 |

#### 1.2 核心功能

- **统一界面**: 通过顶部标签页实现业务记录与审批功能的无缝切换
- **实时同步**: 审批操作后自动刷新记录数据，保持数据一致性
- **视觉区分**: 
  - 业务记录模式：蓝色主题，显示操作记录统计
  - 业务审批模式：橙色主题，显示待审批数量徽章
- **响应式设计**: 适配不同屏幕尺寸，移动端优化

#### 1.3 界面元素

```
│ 业务管理                                 │

│ [业务记录] [业务审批(5)]  ← 模式切换标签  │
├─────────────────────────────────────────┤

│ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐        │

│ 筛选栏                                   │
├─────────────────────────────────────────┤
│ 数据表格                                  │
└─────────────────────────────────────────┘
```

### 2. 出库管理向导式流程重构

#### 2.1 新增文件

| 文件路径 | 说明 |
|---------|------|
| `src/views/inventory-management/outbound/OutboundWizardPage.vue` | 向导式出库管理页面 |
| `src/components/wizard/StepNavigator.vue` | 步骤导航器组件 |
| `src/components/device/DeviceSelector.vue` | 设备选择器组件 |
| `src/components/wizard/index.js` | 向导组件模块导出 |
| `src/components/device/index.js` | 设备组件模块导出 |

#### 2.2 四步向导流程

```
┌─────────────────────────────────────────┐
│ 步骤导航器                               │
│ ●──────●──────●──────●                  │
│ 基本   设备   详细   确认                │
│ 信息   选择   信息   提交                │
└─────────────────────────────────────────┘
```

**步骤1: 基本信息**
- 出库单号（自动生成）
- 出库日期
- 出库仓库
- 经办人
- 联系电话
- 优先级
- 备注

**步骤2: 设备选择**
- 出库类型选择（安装/维修/退货/报废/调拨）
- 设备列表选择
- 数量调整
- 已选设备展示

**步骤3: 详细信息**
- 根据出库类型显示不同字段
  - 安装出库：客户名称、联系人、安装地址、期望日期
  - 维修出库：维修人员、维修单位、故障描述
  - 退货出库：供应商、退货原因
- 附件上传

**步骤4: 确认提交**
- 信息汇总展示
- 确认提交
- 自动跳转到业务管理页面

#### 2.3 核心特性

- **步骤导航器**: 可视化显示当前进度，支持返回已完成的步骤
- **表单验证**: 每个步骤都有完整的字段验证
- **数据暂存**: 自动保存草稿到localStorage，防止数据丢失
- **页面离开提示**: 未提交时离开页面有确认提示
- **响应式布局**: 适配桌面端和移动端

## 技术实现亮点

### 1. 模块化设计

- 组件按功能分类：`wizard/`、`device/`
- 每个模块都有独立的index.js导出文件
- API按业务领域划分

### 2. 代码复用

- 使用现有的`PageLayout`、`DataTable`、`UnifiedFilterBar`等基础组件
- 步骤导航器组件可复用于其他向导式流程
- 设备选择器组件可复用于其他需要选择设备的场景

### 3. 用户体验优化

- 表单验证即时反馈
- 操作成功/失败提示
- 加载状态指示
- 草稿自动保存
- 响应式布局适配

### 4. 状态管理

- 使用Vue 3 Composition API
- 响应式数据管理
- 表单数据分步骤管理
