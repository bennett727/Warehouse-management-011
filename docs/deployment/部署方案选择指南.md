# 仓库管理系统 - 部署方案选择指南

## 📋 三种部署方案对比

| 对比项 | 方案A: Docker部署 | 方案B: 本地运行 | 方案C: 云服务器部署 |
|--------|------------------|-----------------|-------------------|
| **适用场景** | 本地测试/开发 | 本地演示/开发 | 生产环境/正式使用 |
| **难度** | ⭐ 最简单 | ⭐⭐ 简单 | ⭐⭐⭐ 中等 |

| **数据持久化** | ✅ 是 | ✅ 是 | ✅ 是 |
| **开机自启** | ✅ 是 | ❌ 否 | ✅ 是 |

| **性能** | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

## 🚀 快速选择

### 选择方案A（Docker部署）如果你：
- ✅ 想要最简单的一键部署
- ✅ 电脑上已安装Docker Desktop
- ✅ 用于本地测试或演示
- ✅ 不想配置复杂的环境

### 选择方案B（本地运行）如果你：
- ✅ 不想安装Docker
- ✅ 已经配置好了开发环境（JDK、MySQL、Node.js）
- ✅ 用于本地开发调试
- ✅ 想要快速看到效果

### 选择方案C（云服务器部署）如果你：
- ✅ 有阿里云/腾讯云/华为云服务器
- ✅ 需要外网访问（公网IP）
- ✅ 用于正式生产环境
- ✅ 需要7×24小时运行

## 📝 各方案使用说明

### 方案A: Docker一键部署（推荐新手）

#### 前置条件
1. 安装 Docker Desktop
   - Windows: https://www.docker.com/products/docker-desktop
   - Mac: https://docs.docker.com/desktop/install/mac-install/

#### 部署步骤
```bash
# Windows: 双击运行
一键部署.bat

# 或者命令行
docker-compose up --build -d
```

#### 访问地址
- 前端: http://localhost
- 后端API: http://localhost:8080/api

#### 常用命令
```bash
# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 重启服务
docker-compose restart

# 查看状态
docker-compose ps
```

---

### 方案B: 本地运行（使用现有环境）

#### 前置条件
1. 确保MySQL已启动
2. 确保JDK 17已安装
3. 确保Node.js 18已安装

#### 部署步骤
```bash
# Windows: 双击运行
本地部署-方案B.bat

# 然后按提示操作：
# 1. 双击运行生成的"启动后端.bat"
# 2. 打开新终端，运行: cd frontend && npm run dev
```

#### 访问地址
- 前端: http://localhost:5173
- 后端API: http://localhost:8080/api

#### 常用命令
```bash
# 启动后端
cd spring_boot
mvn spring-boot:run

# 启动前端
cd frontend
npm run dev
```

---

### 方案C: 云服务器部署（生产环境）

#### 前置条件
1. 购买云服务器（推荐配置：2核4G以上）
2. 开放安全组端口：80、443、8080
3. 有SSH访问权限

#### 部署步骤

**第一步：上传代码到服务器**
```bash
# 本地执行，将代码上传到服务器
scp -r spring_boot frontend root@你的服务器IP:/opt/wms/
```

**第二步：SSH登录服务器并运行脚本**
```bash
# SSH登录
ssh root@你的服务器IP

# 进入目录
cd /opt/wms

# 运行部署脚本
sudo bash cloud-deploy.sh
```

#### 访问地址
- 前端: http://你的服务器IP
- 后端API: http://你的服务器IP/api

#### 常用命令
```bash
# 查看日志
sudo journalctl -u wms -f

# 重启服务
sudo systemctl restart wms

# 停止服务
sudo systemctl stop wms

# 查看状态
sudo systemctl status wms

# 查看Nginx日志
sudo tail -f /var/log/nginx/access.log
```

## 🔧 配置文件说明

### 数据库配置（所有方案通用）

```properties
# 数据库连接
DB_URL=jdbc:mysql://localhost:3306/warehouse
DB_USERNAME=wms
DB_PASSWORD=wms123
```

### JWT密钥配置（生产环境必改）

```properties
# 生成新密钥
openssl rand -base64 64

# 替换配置中的JWT_SECRET
JWT_SECRET=你的新密钥
```

### CORS配置（根据部署方式调整）

```properties
# Docker部署
cors.allowed-origins=http://localhost

# 本地运行
cors.allowed-origins=http://localhost:5173,http://localhost:8080

# 云服务器部署（替换为你的域名或IP）
cors.allowed-origins=http://your-domain.com,http://your-server-ip
```

## 🐛 常见问题

### Q1: Docker部署时端口被占用
**解决：**
```bash
# 查看占用端口的进程
netstat -ano | findstr :80

# 停止占用端口的进程，或修改docker-compose.yml中的端口映射
# 例如将 80:80 改为 8080:80
```

### Q2: 本地运行提示MySQL未启动
**解决：**
```bash
# Windows: 打开服务管理器，启动MySQL
services.msc

# 或命令行
net start MySQL80
```

### Q3: 云服务器部署后无法访问
**解决：**
1. 检查安全组规则，确保开放了80端口
2. 检查防火墙
   ```bash
   sudo firewall-cmd --list-ports
   sudo firewall-cmd --add-port=80/tcp --permanent
   sudo firewall-cmd --reload
   ```
3. 检查服务状态
   ```bash
   sudo systemctl status wms
   sudo systemctl status nginx
   ```

### Q4: 登录失败或Token过期
**解决：**
- 检查浏览器控制台是否有CORS错误
- 检查后端日志是否有认证错误
- 清除浏览器缓存和Cookie

## 🔒 安全建议

### 生产环境必做

1. **修改默认密码**
   - 管理员密码：admin123 → 强密码
   - 数据库密码：使用随机生成的强密码

2. **配置SSL证书（HTTPS）**
   ```bash
   # 使用Let's Encrypt免费证书
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d your-domain.com
   ```

3. **配置防火墙**
   ```bash
   # 只开放必要端口
   sudo ufw allow 80/tcp
   sudo ufw allow 443/tcp
   sudo ufw enable
   ```

4. **定期备份**
   ```bash
   # 数据库备份脚本
   mysqldump -u wms_user -p warehouse > backup_$(date +%Y%m%d).sql
   ```
