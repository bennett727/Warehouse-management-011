## 2. 部署执行阶段

### 2.1 部署前备份

#### 2.1.1 数据库备份

```bash
# 创建备份目录
mkdir -p /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)

# 备份生产数据库
mysqldump -h prod-db-server -u wms_prod_user -p \
  --single-transaction \
  --routines \
  --triggers \
  --events \
  --databases warehouse \
  > /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/warehouse_backup.sql

# 压缩备份文件
gzip /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/warehouse_backup.sql

# 验证备份文件
ls -lh /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/
```

#### 2.1.2 应用备份

```bash
# 备份当前应用版本
cp /opt/wms/app/spring_boot.jar \
   /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/spring_boot-previous.jar

# 备份配置文件
cp /opt/wms/.env \
   /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/.env.backup

# 备份上传文件
tar -czf /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/uploads-backup.tar.gz \
   /opt/wms/uploads/
```

#### 2.1.3 验证备份

```bash
# 验证数据库备份
zcat /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/warehouse_backup.sql.gz | \
  head -n 20

# 验证应用备份
ls -lh /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/

# 记录备份信息
echo "部署前备份完成 - 时间: $(date)" >> /opt/wms/logs/deployment.log
echo "备份目录: /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/" >> /opt/wms/logs/deployment.log
```

#### 4.1.1 切换流量到绿色环境

upstream wms_prod_backend {
    least_conn;
    server 192.168.2.10:8080 weight=0;  # 蓝色环境（下线）

## 6. 回滚流程

### 6.1 回滚触发条件

出现以下情况时，应立即执行回滚：

- [ ] 应用无法启动
- [ ] 核心功能异常
- [ ] 性能严重下降
- [ ] 数据损坏或丢失
- [ ] 安全漏洞暴露
- [ ] 用户投诉激增

### 6.2 回滚执行步骤

#### 6.2.1 立即停止应用

```bash
# 停止当前应用
systemctl stop wms

# 确认应用已停止
systemctl status wms
```

#### 6.2.2 恢复数据库

```bash
# 恢复数据库备份
gunzip < /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/warehouse_backup.sql.gz | \
  mysql -h prod-db-server -u wms_prod_user -p warehouse

# 验证数据库恢复
mysql -h prod-db-server -u wms_prod_user -p warehouse -e "
SHOW TABLES;
SELECT COUNT(*) FROM user;
"
```

#### 6.2.3 恢复应用

```bash
# 恢复应用版本
cp /opt/wms/backup/pre-deploy-$(date +%Y%m%d_%H%M%S)/spring_boot-previous.jar \
   /opt/wms/app/spring_boot.jar

# 启动应用
systemctl start wms

# 等待应用启动
sleep 30

# 检查应用状态
systemctl status wms
```

#### 6.2.4 验证回滚

```bash
# 检查应用日志
tail -f /opt/wms/logs/spring-boot.log

# 检查应用健康状态
curl -X GET http://localhost:8080/api/actuator/health

# 执行冒烟测试
./scripts/smoke-test.sh

# 记录回滚信息
echo "回滚完成 - 时间: $(date)" >> /opt/wms/logs/deployment.log
```
