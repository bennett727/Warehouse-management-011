# 生产环境部署检查清单

## 📋 部署前准备

### 1. 环境检查

- [ ] **服务器环境**
  - [ ] 操作系统：Windows Server 2019+ / Linux Ubuntu 20.04+
  - [ ] Java 17 已安装并配置环境变量
  - [ ] Node.js 18+ 已安装（前端构建需要）
  - [ ] MySQL 8.0 已安装并运行
  - [ ] Nginx/Apache 已安装（反向代理）

- [ ] **端口检查**
  - [ ] 8080 端口可用（后端服务）
  - [ ] 80/443 端口可用（Web服务）
  - [ ] 3306 端口可用（MySQL，如本地部署）

### 2. 配置文件检查

- [ ] **后端配置** (`spring_boot/src/main/resources/application-prod.properties`)
  - [ ] 数据库连接配置正确
  - [ ] JWT密钥已设置为强密码（≥32位随机字符串）
  - [ ] 管理员密码已修改（非默认密码）
  - [ ] 日志级别设置为 WARN 或 ERROR
  - [ ] 文件上传路径已配置

- [ ] **前端配置** (`frontend/.env.production`)
  - [ ] API基础URL指向正确
  - [ ] 生产环境标识已设置

### 3. 安全设置

- [ ] **环境变量**
  ```bash
  # 必须设置的环境变量
  export DB_PASSWORD=<强密码>
  export JWT_SECRET=<32位以上随机字符串>
  export MYSQL_ROOT_PASSWORD=<强密码>
  ```

- [ ] **防火墙规则**
  - [ ] 仅开放必要端口（80, 443, 8080）
  - [ ] 数据库端口不对外暴露
  - [ ] SSH访问限制IP

## 🔨 部署步骤

### 步骤1：数据库准备

- [ ] 创建生产数据库
  ```sql
  CREATE DATABASE wms_prod CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  ```

- [ ] 执行数据库初始化脚本
  ```bash
  # 使用Flyway或手动执行
  mysql -u root -p wms_prod < database/init.sql
  ```

- [ ] 验证数据库连接

### 步骤2：后端部署

- [ ] 构建后端项目
  ```bash
  cd spring_boot
  mvn clean package -DskipTests -P prod
  ```

- [ ] 验证构建产物
  - [ ] `target/wms-backend-*.jar` 文件存在
  - [ ] 文件大小正常（>50MB）

- [ ] 部署JAR文件
  ```bash
  # 复制到部署目录
  cp target/wms-backend-*.jar /opt/wms/backend/
  ```

- [ ] 创建服务配置文件（Systemd）
  ```ini
  # /etc/systemd/system/wms-backend.service
  [Unit]
  Description=WMS Backend Service
  After=network.target

  [Service]
  Type=simple
  User=wms
  Environment=DB_PASSWORD=<密码>
  Environment=JWT_SECRET=<密钥>
  ExecStart=/usr/bin/java -jar /opt/wms/backend/wms-backend.jar
  Restart=always

  [Install]
  WantedBy=multi-user.target
  ```

### 步骤3：前端部署

- [ ] 安装依赖
  ```bash
  cd frontend
  npm ci --production
  ```

- [ ] 构建生产版本
  ```bash
  npm run build
  ```

- [ ] 验证构建产物
  - [ ] `dist/` 目录存在
  - [ ] `dist/index.html` 存在
  - [ ] 静态资源文件存在

- [ ] 部署到Web服务器
  ```bash
  # 复制到Nginx目录
  cp -r dist/* /var/www/wms/
  ```

### 步骤4：Web服务器配置

- [ ] **Nginx配置**
  ```nginx
  server {
      listen 80;
      server_name wms.yourcompany.com;
      
      # 重定向到HTTPS
      return 301 https://$server_name$request_uri;
  }

  server {
      listen 443 ssl http2;
      server_name wms.yourcompany.com;

      # SSL证书配置
      ssl_certificate /path/to/cert.pem;
      ssl_certificate_key /path/to/key.pem;

      # 前端静态资源
      location / {
          root /var/www/wms;
          try_files $uri $uri/ /index.html;
      }

      # 后端API代理
      location /api/ {
          proxy_pass http://localhost:8080/api/;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
      }
  }
  ```

- [ ] 测试Nginx配置
  ```bash
  nginx -t
  ```

- [ ] 重载Nginx
  ```bash
  systemctl reload nginx
  ```

## 🆘 常见问题

### 1. 后端启动失败

**症状**：服务无法启动，日志显示端口被占用

**解决方案**：
```bash
# 查找占用8080端口的进程
netstat -tlnp | grep 8080
# 终止进程
kill -9 <PID>
# 重启服务
systemctl restart wms-backend
```

### 2. 前端页面空白

**症状**：访问首页显示空白页面

**解决方案**：
- 检查Nginx配置中的root路径
- 确认dist文件已正确复制
- 检查浏览器控制台错误

### 3. 数据库连接失败

**症状**：后端日志显示数据库连接错误

**解决方案**：
- 验证数据库服务运行状态
- 检查连接字符串和密码
- 确认数据库用户权限

### 4. API 404错误

**症状**：前端调用API返回404

**解决方案**：
- 检查Nginx代理配置
- 确认后端服务正常运行
- 验证API路径正确
