# 仓库管理系统测试环境配置规范

## 1. 测试环境概述

### 1.1 测试环境定义

测试环境是介于开发环境和生产环境之间的中间环境，用于：
- 功能测试：验证系统功能是否符合需求
- 集成测试：验证各模块之间的集成是否正常
- 性能测试：评估系统性能和稳定性
- 安全测试：检查系统安全漏洞
- 用户验收测试（UAT）：用户验证系统是否满足业务需求

## 2. 服务器配置规范

### 2.1 应用服务器配置

#### 硬件配置
| 配置项 | 最低要求 | 推荐配置 |
|--------|---------|---------|
| CPU | 4核 | 8核 |
| 内存 | 8GB | 16GB |
| 磁盘 | 100GB SSD | 200GB SSD |
| 网络 | 1Gbps | 10Gbps |

#### 软件环境
| 软件名称 | 版本要求 | 说明 |
|---------|---------|------|
| 操作系统 | CentOS 7.9 / Ubuntu 20.04 | 推荐使用CentOS 7.9 |
| JDK | OpenJDK 17 | 必须使用JDK 17 |
| Maven | 3.8+ | 用于构建应用 |
| Nginx | 1.18+ | 用于负载均衡 |

#### 系统配置
```bash
# 1. 创建应用用户
useradd -m -s /bin/bash wms
usermod -aG wheel wms

# 2. 创建应用目录
mkdir -p /opt/wms/{app,logs,backup,uploads}
chown -R wms:wms /opt/wms

# 3. 配置系统参数
cat >> /etc/sysctl.conf << EOF
# 网络参数优化
net.core.somaxconn = 65535
net.ipv4.tcp_max_syn_backlog = 8192
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_fin_timeout = 30
net.ipv4.tcp_keepalive_time = 1200
net.ipv4.ip_local_port_range = 10000 65000

# 文件描述符限制
fs.file-max = 65535
EOF

sysctl -p

# 4. 配置用户限制
cat >> /etc/security/limits.conf << EOF
wms soft nofile 65535
wms hard nofile 65535
wms soft nproc 65535
wms hard nproc 65535
EOF

# 5. 配置防火墙

firewall-cmd --permanent --add-port=80/tcp
```

### 4.2 Nginx负载均衡配置

创建`/etc/nginx/conf.d/wms-test.conf`文件：
```nginx
upstream wms_test_backend {
    least_conn;
    server 192.168.1.10:8080 weight=1;
    server 192.168.1.11:8080 weight=1;
    server 192.168.1.12:8080 weight=1;

server {
    listen 80;
    server_name test.wms.com;

    # 日志配置
    access_log /var/log/nginx/wms-test-access.log;
    error_log /var/log/nginx/wms-test-error.log;

    # 请求体大小限制
    client_max_body_size 100M;

    # 代理配置
    location /api/ {
        proxy_pass http://wms_test_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
        
        # 缓冲配置
        proxy_buffering on;
        proxy_buffer_size 4k;
        proxy_buffers 8 4k;
        proxy_busy_buffers_size 8k;
        
        # WebSocket支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 静态文件服务
    location /uploads/ {
        alias /opt/wms/uploads/;
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    # 健康检查
    location /health {
        access_log off;
        return 200 "healthy\n";
        add_header Content-Type text/plain;
    }
}
```

### 5.3 数据备份策略

```bash
# 每日备份脚本
cat > /opt/wms/scripts/backup-database.sh << 'EOF'
#!/bin/bash

BACKUP_DIR="/opt/wms/backup/database"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="warehouse_test_${DATE}.sql"

mkdir -p ${BACKUP_DIR}

# 备份数据库
mysqldump -h 192.168.1.20 -u wms_test_user -pTest@2024 \
  --single-transaction \
  --routines \
  --triggers \
  --events \
  warehouse_test > ${BACKUP_DIR}/${BACKUP_FILE}

# 压缩备份文件
gzip ${BACKUP_DIR}/${BACKUP_FILE}

# 删除7天前的备份
find ${BACKUP_DIR} -name "warehouse_test_*.sql.gz" -mtime +7 -delete

echo "Database backup completed: ${BACKUP_FILE}.gz"
EOF

chmod +x /opt/wms/scripts/backup-database.sh

# 添加到crontab（每天凌晨2点执行）
crontab -e
# 添加以下行：
# 0 2 * * * /opt/wms/scripts/backup-database.sh >> /opt/wms/logs/backup.log 2>&1
```

## 7. 测试环境使用规范

### 7.1 访问权限管理

| 角色 | 用户 | 权限范围 |
|------|------|---------|
| 测试管理员 | test_admin | 完全访问权限 |
| 测试工程师 | test_engineer | 测试执行权限 |
| 测试观察员 | test_viewer | 只读权限 |

### 7.2 数据管理规范

1. **测试数据管理**
   - 定期刷新测试数据（每周一次）
   - 使用脱敏的生产数据
   - 保留测试数据的历史版本

2. **数据隔离**
   - 不同测试团队使用不同的数据集
   - 并发测试使用独立的数据空间
   - 测试完成后清理临时数据

3. **数据备份**
   - 每日自动备份测试数据库
   - 保留最近7天的备份
   - 重要测试前手动备份

### 7.3 测试执行规范

1. **测试计划**
   - 每次测试前制定测试计划
   - 明确测试范围和目标
   - 分配测试资源和时间

2. **测试执行**
   - 按照测试用例执行测试
   - 记录测试结果和问题

```bash
# 查看应用状态

# 查看网络连接
netstat -tlnp | grep 8080

ps aux | grep spring_boot

# 查看JVM内存使用
jstat -gc <pid> 1s 10
```

### 8.2 故障排查指南

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 应用无法启动 | 端口被占用 | 检查端口占用，修改配置或停止占用进程 |
| 数据库连接失败 | 网络不通或密码错误 | 检查网络连接，验证数据库配置 |
| Redis连接失败 | Redis服务未启动 | 启动Redis服务，检查配置 |
| 内存溢出 | JVM内存不足 | 增加JVM内存配置，优化代码 |
| 响应慢 | 数据库查询慢 | 优化SQL语句，添加索引 |
| 磁盘空间不足 | 日志文件过大 | 清理日志文件，配置日志轮转 |
