## 2. 服务器配置规范

### 2.1 应用服务器配置

#### 硬件配置要求

| 配置项 | 最低要求 | 推荐配置 | 说明 |
|--------|---------|---------|------|
| CPU | 8核 | 16核 | 支持高并发请求处理 |
| 内存 | 16GB | 32GB | JVM堆内存建议8-16GB |
| 磁盘 | 200GB SSD | 500GB NVMe SSD | 系统盘+数据盘分离 |
| 网络 | 1Gbps | 10Gbps | 内网通信带宽 |

#### 软件环境要求

| 软件名称 | 版本要求 | 说明 |
|---------|---------|------|
| 操作系统 | CentOS 7.9 / Ubuntu 22.04 LTS | 64位系统 |
| JDK | OpenJDK 21 LTS | 必须使用JDK 21 |
| Nginx | 1.24+ | 反向代理和负载均衡 |
| Node.js | 20.x LTS | 前端构建环境 |

### 2.2 数据库服务器配置

#### MySQL主库配置

| 配置项 | 规格 | 说明 |
|--------|------|------|
| CPU | 16核 | 处理写操作和复杂查询 |
| 内存 | 64GB | InnoDB缓冲池建议48GB |
| 磁盘 | 1TB NVMe SSD RAID 10 | 数据持久化存储 |
| 网络 | 10Gbps | 主从复制带宽 |

#### MySQL从库配置

| 配置项 | 规格 | 说明 |
|--------|------|------|
| CPU | 8核 | 处理读操作 |
| 内存 | 32GB | InnoDB缓冲池建议24GB |

### 2.3 Redis缓存服务器配置

| 配置项 | 规格 | 说明 |

### 4.2 Nginx配置

```nginx
# =============================================================================
# Nginx生产环境配置
# 版本: 1.0.0
# 更新日期: 2026-02-08
# =============================================================================

user nginx;
worker_processes auto;
error_log /var/log/nginx/error.log warn;
pid /var/run/nginx.pid;

events {
    worker_connections 4096;
    use epoll;
    multi_accept on;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    # 日志格式
    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" "$http_x_forwarded_for" '
                    'rt=$request_time uct="$upstream_connect_time" '
                    'uht="$upstream_header_time" urt="$upstream_response_time"';

    access_log /var/log/nginx/access.log main;

    # 性能优化
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;
    types_hash_max_size 2048;
    client_max_body_size 200M;

    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_proxied expired no-cache no-store private auth;
    gzip_types text/plain text/css text/xml text/javascript application/x-javascript application/xml application/javascript;

    # 上游服务器配置
    upstream backend {
        least_conn;
        server 192.168.1.10:8080 weight=5 max_fails=3 fail_timeout=30s;
        server 192.168.1.11:8080 weight=5 max_fails=3 fail_timeout=30s;
        server 192.168.1.12:8080 weight=5 max_fails=3 fail_timeout=30s backup;
        keepalive 32;
    }

    upstream frontend {
        least_conn;
        server 192.168.1.10:80 weight=5 max_fails=3 fail_timeout=30s;
        server 192.168.1.11:80 weight=5 max_fails=3 fail_timeout=30s;
        server 192.168.1.12:80 weight=5 max_fails=3 fail_timeout=30s backup;
    }

    # HTTP重定向到HTTPS
    server {
        listen 80;
        server_name wms.company.com;
        return 301 https://$server_name$request_uri;
    }

    # HTTPS服务器配置
    server {
        listen 443 ssl http2;
        server_name wms.company.com;

        # SSL证书配置
        ssl_certificate /etc/nginx/ssl/wms.company.com.crt;
        ssl_certificate_key /etc/nginx/ssl/wms.company.com.key;
        ssl_session_timeout 1d;
        ssl_session_cache shared:SSL:50m;
        ssl_session_tickets off;
        ssl_protocols TLSv1.2 TLSv1.3;
        ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384;
        ssl_prefer_server_ciphers off;

        # HSTS配置
        add_header Strict-Transport-Security "max-age=63072000" always;

        # 安全响应头
        add_header X-Frame-Options "SAMEORIGIN" always;
        add_header X-Content-Type-Options "nosniff" always;
        add_header X-XSS-Protection "1; mode=block" always;
        add_header Referrer-Policy "strict-origin-when-cross-origin" always;

        # 前端静态资源
        location / {
            proxy_pass http://frontend;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection 'upgrade';
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_cache_bypass $http_upgrade;
            proxy_read_timeout 86400;
        }

        # API代理
        location /api/ {
            proxy_pass http://backend;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection 'upgrade';
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_cache_bypass $http_upgrade;
            proxy_read_timeout 300;
            proxy_connect_timeout 300;
            proxy_send_timeout 300;
        }

        # 静态文件缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            proxy_pass http://frontend;
            expires 1y;
            add_header Cache-Control "public, immutable";
            add_header X-Cache-Status $upstream_cache_status;
        }
    }
}
```

## 5. 部署流程

### 5.1 部署前检查清单

- [ ] 数据库备份已完成
- [ ] 配置文件已更新并验证
- [ ] 环境变量已正确设置
- [ ] SSL证书已安装且未过期
- [ ] 监控告警已配置
- [ ] 回滚方案已准备

### 5.2 部署步骤

```bash
#!/bin/bash
# deploy.sh - 生产环境部署脚本
# 版本: 1.0.0
# 更新日期: 2026-02-08

set -e

echo "=========================================="
echo "仓库管理系统生产环境部署"
echo "=========================================="

# 1. 备份当前版本
echo "[1/7] 备份当前版本..."
BACKUP_DIR="/opt/wms/backup/$(date +%Y%m%d_%H%M%S)"
mkdir -p $BACKUP_DIR
cp -r /opt/wms/app/* $BACKUP_DIR/ 2>/dev/null || true

# 2. 拉取最新代码
echo "[2/7] 拉取最新代码..."
cd /opt/wms/source
git pull origin main

# 3. 构建后端
echo "[3/7] 构建后端服务..."
cd /opt/wms/source/spring_boot
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk
mvn clean package -DskipTests -Pprod

# 4. 构建前端
echo "[4/7] 构建前端应用..."
cd /opt/wms/source/frontend
npm ci
npm run build

# 5. 停止旧服务
echo "[5/7] 停止旧服务..."
systemctl stop wms-backend || true

# 6. 部署新版本
echo "[6/7] 部署新版本..."
cp /opt/wms/source/spring_boot/target/*.jar /opt/wms/app/backend.jar
cp -r /opt/wms/source/frontend/dist/* /opt/wms/app/frontend/

# 7. 启动新服务
echo "[7/7] 启动新服务..."
systemctl start wms-backend
systemctl reload nginx

# 8. 健康检查
echo "执行健康检查..."
sleep 10
if curl -sf http://localhost:8080/api/health > /dev/null; then
    echo "✅ 部署成功！"
else
    echo "❌ 健康检查失败，执行回滚..."
    # 回滚逻辑
    systemctl stop wms-backend
    cp -r $BACKUP_DIR/* /opt/wms/app/
    systemctl start wms-backend
    exit 1
fi

echo "=========================================="
echo "部署完成！"
echo "备份目录: $BACKUP_DIR"
echo "=========================================="
```

## 6. 监控与告警

### 6.1 监控指标

| 指标类型 | 指标名称 | 告警阈值 | 说明 |
|---------|---------|---------|------|
| 系统 | CPU使用率 | > 80% | 持续5分钟 |
| 系统 | 内存使用率 | > 85% | 持续5分钟 |
| 系统 | 磁盘使用率 | > 90% | 立即告警 |
| 应用 | JVM堆内存 | > 80% | 持续3分钟 |
| 应用 | GC频率 | > 10次/分钟 | 持续5分钟 |
| 应用 | 响应时间 | > 2秒 | P99指标 |
| 应用 | 错误率 | > 1% | 持续5分钟 |
| 数据库 | 连接数 | > 80% | 连接池使用率 |
| 数据库 | 慢查询 | > 1秒 | 单条SQL执行时间 |

### 6.2 告警通知

## 7. 安全加固

### 7.1 系统安全

- 禁用root远程登录
- 配置防火墙规则，仅开放必要端口
- 定期更新系统补丁
- 启用SELinux或AppArmor

### 7.2 应用安全

- 启用HTTPS，配置HSTS
- 配置CSP内容安全策略
- 启用WAF防护
- 定期更新依赖库，修复安全漏洞

### 7.3 数据安全

- 数据库定期备份（每日全量+实时增量）
- 敏感数据加密存储
- 配置数据库审计日志
- 定期执行安全扫描

## 8. 故障处理

### 8.1 常见故障及解决方案

| 故障现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 服务无法启动 | 端口被占用 | 检查端口占用情况，修改配置 |
| 数据库连接失败 | 网络不通或认证失败 | 检查网络连接和凭据 |
| 内存溢出 | JVM配置不当 | 调整JVM堆内存参数 |
| 响应缓慢 | 数据库慢查询 | 优化SQL，添加索引 |
| 502错误 | 后端服务不可用 | 检查后端健康状态 |

### 8.2 紧急回滚流程

```bash
# 紧急回滚脚本
#!/bin/bash
set -e

BACKUP_DIR="$1"
if [ -z "$BACKUP_DIR" ]; then
    echo "请指定备份目录"
    exit 1
fi

echo "执行紧急回滚..."
systemctl stop wms-backend
cp -r $BACKUP_DIR/* /opt/wms/app/
systemctl start wms-backend
systemctl reload nginx
echo "回滚完成"
```
