# 仓库管理系统环境迁移策略

## 1. 环境架构概述

### 1.1 环境定义

| 环境 | 用途 | 数据库类型 | 配置文件 | 端口 | 访问地址 |
|------|------|-----------|----------|------|----------|
| **开发环境** | 本地开发调试 | H2内存数据库 | `application-dev.properties` | 8080 | http://localhost:8080 |
| **测试环境** | 功能测试、集成测试 | MySQL 8.0 | `application-test.properties` | 8080 | http://test.wms.com:8080 |
| **生产环境** | 正式运行环境 | MySQL 8.0 | `application-prod.properties` | 8080 | https://www.wms.com:8080 |

### 1.2 环境隔离原则

1. **数据隔离**：每个环境使用独立的数据库实例
2. **配置隔离**：每个环境使用独立的配置文件
3. **网络隔离**：生产环境与开发/测试环境网络隔离
4. **权限隔离**：不同环境使用不同的访问权限和认证密钥

## 2. 数据库迁移策略

### 2.1 数据库配置对比

#### 开发环境（H2）
```properties
spring.datasource.url=jdbc:h2:mem:warehouse_dev;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE;MODE=MySQL
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=
spring.jpa.hibernate.ddl-auto=update
```

#### 测试环境（MySQL）
```properties
spring.datasource.url=jdbc:mysql://test-db-server:3306/warehouse_test?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
spring.datasource.username=wms_test_user
spring.datasource.password=Test@2024
spring.jpa.hibernate.ddl-auto=validate
```

#### 生产环境（MySQL）
```properties
spring.datasource.url=jdbc:mysql://prod-db-server:3306/warehouse?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&useSSL=true
spring.datasource.username=wms_prod_user
spring.datasource.password=${DB_PASSWORD}
spring.jpa.hibernate.ddl-auto=validate
```

### 2.2 数据迁移步骤

#### 步骤1：准备MySQL数据库

```sql
-- 创建测试环境数据库
CREATE DATABASE warehouse_test 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- 创建生产环境数据库
CREATE DATABASE warehouse 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- 创建数据库用户
CREATE USER 'wms_test_user'@'%' IDENTIFIED BY 'Test@2024';
CREATE USER 'wms_prod_user'@'%' IDENTIFIED BY 'Prod@2024';

-- 授予权限
GRANT ALL PRIVILEGES ON warehouse_test.* TO 'wms_test_user'@'%';
GRANT ALL PRIVILEGES ON warehouse.* TO 'wms_prod_user'@'%';

FLUSH PRIVILEGES;
```

#### 步骤2：数据结构迁移

```bash
# 使用Flyway进行数据库版本管理
mvn flyway:migrate -Dflyway.configFiles=src/main/resources/db/migration/test/flyway.conf
```

#### 步骤3：测试数据迁移

```bash
# 导出H2测试数据
java -cp h2.jar org.h2.tools.Script -url jdbc:h2:mem:warehouse_dev -user sa -script test_data.sql

# 转换并导入MySQL
mysql -h test-db-server -u wms_test_user -p warehouse_test < test_data.sql
```

### 2.3 数据迁移验证

```bash
# 验证表结构
mysql -h test-db-server -u wms_test_user -p warehouse_test -e "SHOW TABLES;"

# 验证数据完整性
mysql -h test-db-server -u wms_test_user -p warehouse_test -e "
SELECT 
    'user' as table_name, COUNT(*) as record_count FROM user
UNION ALL
SELECT 'device', COUNT(*) FROM device
UNION ALL
SELECT 'warehouse', COUNT(*) FROM warehouse;
"

# 验证外键约束
mysql -h test-db-server -u wms_test_user -p warehouse_test -e "
SELECT 
    TABLE_NAME, CONSTRAINT_NAME, REFERENCED_TABLE_NAME
FROM information_schema.KEY_COLUMN_USAGE
WHERE TABLE_SCHEMA = 'warehouse_test'
AND REFERENCED_TABLE_NAME IS NOT NULL;
"
```

## 3. 配置文件迁移

### 3.1 配置文件结构

```
src/main/resources/
├── application.properties              # 主配置文件（所有环境共用）
├── application-dev.properties          # 开发环境配置
├── application-test.properties         # 测试环境配置
├── application-prod.properties         # 生产环境配置
├── db/
│   ├── migration/
│   │   ├── dev/                       # 开发环境数据库迁移脚本
│   │   ├── test/                      # 测试环境数据库迁移脚本
│   │   └── prod/                      # 生产环境数据库迁移脚本
└── sql/
    ├── init_test_data_h2.sql          # H2测试数据初始化脚本
    └── init_test_data_mysql.sql       # MySQL测试数据初始化脚本
```

## 4. 应用部署流程

### 4.1 开发环境 → 测试环境

#### 前置条件检查清单
- [ ] 测试环境MySQL数据库已创建并配置完成
- [ ] 测试环境Redis服务已启动
- [ ] 测试环境网络连接正常
- [ ] 测试环境端口8080未被占用
- [ ] 测试环境防火墙规则已配置

#### 部署步骤

1. **代码提交与构建**
```bash
# 提交代码到Git仓库
git add .
git commit -m "feat: 准备测试环境部署"
git push origin develop

# 构建应用
mvn clean package -DskipTests -Ptest
```

2. **上传部署包**
```bash
# 上传JAR包到测试服务器
scp target/spring_boot-*.jar user@test-server:/opt/wms/
```

3. **配置环境变量**
```bash
# 在测试服务器上设置环境变量
cat > /opt/wms/.env << EOF
SPRING_PROFILES_ACTIVE=test
DB_URL=jdbc:mysql://test-db-server:3306/warehouse_test
DB_USERNAME=wms_test_user
DB_PASSWORD=Test@2024
EOF

# 设置文件权限
chmod 600 /opt/wms/.env
```

4. **启动应用**
```bash
# 停止旧版本应用
systemctl stop wms-test

# 备份旧版本
mv /opt/wms/spring_boot.jar /opt/wms/backup/spring_boot-$(date +%Y%m%d).jar

# 部署新版本
mv /opt/wms/spring_boot-*.jar /opt/wms/spring_boot.jar

# 启动新版本应用
systemctl start wms-test

# 检查应用状态
systemctl status wms-test
```

5. **验证部署**
```bash
# 检查应用日志
tail -f /var/log/warehouse-management/spring-boot.log

# 检查数据库连接
curl -X GET http://test.wms.com:8080/api/database/status \
  -H "Authorization: Bearer <token>"

# 检查健康状态
curl -X GET http://test.wms.com:8080/api/actuator/health
```

### 4.2 测试环境 → 生产环境

#### 前置条件检查清单
- [ ] 生产环境MySQL数据库已创建并配置完成
- [ ] 生产环境Redis服务已启动
- [ ] 生产环境SSL证书已配置
- [ ] 生产环境防火墙规则已配置
- [ ] 生产环境备份策略已配置
- [ ] 生产环境监控告警已配置
- [ ] 测试环境所有测试用例通过
- [ ] 测试环境性能测试通过

#### 部署步骤

1. **代码合并与构建**
```bash
# 合并到main分支
git checkout main
git merge develop
git push origin main

# 打标签
git tag -a v1.0.0 -m "生产环境发布版本1.0.0"
git push origin v1.0.0

# 构建生产版本
mvn clean package -DskipTests -Pprod
```

2. **数据备份**
```bash
# 备份生产数据库
mysqldump -h prod-db-server -u wms_prod_user -p warehouse > backup_$(date +%Y%m%d).sql

# 备份当前应用
cp /opt/wms/spring_boot.jar /opt/wms/backup/spring_boot-$(date +%Y%m%d).jar
```

3. **部署应用**
```bash
# 上传JAR包到生产服务器
scp target/spring_boot-*.jar user@prod-server:/opt/wms/

# 停止应用（蓝绿部署）
systemctl stop wms-green

# 部署新版本到绿色环境
mv /opt/wms/spring_boot-*.jar /opt/wms/spring_boot-green.jar

# 启动绿色环境
systemctl start wms-green

# 健康检查
curl -X GET http://prod-server:8080/api/actuator/health

# 切换流量
systemctl stop wms-blue
systemctl start wms-blue
```

4. **验证部署**
```bash
# 检查应用日志
tail -f /var/log/warehouse-management/spring-boot.log

# 检查数据库连接
curl -X GET https://www.wms.com/api/database/status \
  -H "Authorization: Bearer <token>"

# 执行冒烟测试
./scripts/smoke-test.sh
```

## 5. 回滚策略

### 5.1 数据库回滚

```bash
# 停止应用
systemctl stop wms

# 恢复数据库备份
mysql -h prod-db-server -u wms_prod_user -p warehouse < backup_20240101.sql

# 恢复应用版本
cp /opt/wms/backup/spring_boot-20240101.jar /opt/wms/spring_boot.jar

# 启动应用
systemctl start wms

# 验证回滚
curl -X GET https://www.wms.com/api/actuator/health
```

### 5.2 应用回滚

```bash
# 快速回滚到上一个版本
systemctl stop wms
cp /opt/wms/backup/spring_boot-$(date +%Y%m%d).jar /opt/wms/spring_boot.jar
systemctl start wms
```

## 6. 监控与告警

### 6.1 监控指标

| 指标类型 | 监控项 | 阈值 | 告警级别 |
|---------|--------|------|---------|
| 应用性能 | 响应时间 | > 2s | WARNING |
| 应用性能 | 错误率 | > 1% | CRITICAL |
| 数据库 | 连接数 | > 80% | WARNING |
| 数据库 | 查询时间 | > 1s | WARNING |
| 数据库 | 连接失败 | > 5次/分钟 | CRITICAL |
| 系统 | CPU使用率 | > 80% | WARNING |
| 系统 | 内存使用率 | > 85% | WARNING |
| 系统 | 磁盘使用率 | > 90% | CRITICAL |

### 6.2 告警通知

- **WARNING级别**：发送邮件通知
- **CRITICAL级别**：发送邮件+短信+电话通知

## 8. 附录

### 8.1 常用命令

```bash
# 查看应用状态
systemctl status wms

# 查看应用日志
journalctl -u wms -f

# 重启应用
systemctl restart wms

# 查看数据库连接
mysql -h db-server -u wms_user -p -e "SHOW PROCESSLIST;"

# 查看数据库表大小
mysql -h db-server -u wms_user -p warehouse -e "
SELECT 
    TABLE_NAME, 
    ROUND((DATA_LENGTH + INDEX_LENGTH) / 1024 / 1024, 2) AS 'Size (MB)'
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'warehouse'
ORDER BY (DATA_LENGTH + INDEX_LENGTH) DESC;
"

# 查看应用端口占用
netstat -tlnp | grep 8080

# 查看应用进程
ps aux | grep spring_boot

# 查看JVM内存使用
jstat -gc <pid> 1s 10
```
