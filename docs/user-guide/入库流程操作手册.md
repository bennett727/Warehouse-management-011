## 一、流程概述

### 1.1 新流程特点

本次升级对入库流程进行了优化，主要变化如下：

| 流程环节 | 旧流程 | 新流程 | 说明 |
|---------|-------|-------|------|
| 创建入库单 | 填写入库信息 | 填写入库信息+创建设备 | 创建设备时状态为"待入库" |
| 审批环节 | 审批通过后执行入库 | 审批通过即完成入库 | 审批后设备自动变为"在库" |
| 执行入库 | 单独的执行操作 | 已取消 | 审批即完成，无需额外操作 |
| 设备可见性 | 入库后可见 | 审批后可见 | 待入库设备在设备列表中显示为"待入库" |

### 1.2 状态流转图

```
┌─────────────┐    创建入库单    ┌─────────────┐    审批通过    ┌─────────────┐
│   无设备    │ ─────────────→ │   待入库    │ ───────────→ │    在库     │
└─────────────┘                └─────────────┘               └─────────────┘
                                      │                            │
                                      │ 审批拒绝                     │ 出库
                                      ↓                            ↓
                               ┌─────────────┐               ┌─────────────┐
                               │   已删除    │               │   使用中    │
                               └─────────────┘               └─────────────┘
```

## 二、操作步骤详解

### 2.1 创建入库单

#### 操作路径
**库存管理** → **入库管理** → **新增入库单**

#### 操作步骤

1. **填写基本信息**
   - 选择供应商（必填）
   - 选择目标仓库/区域/货位（必填）
   - 填写备注（选填）

2. **添加设备信息**
   - 点击"添加设备"按钮
   - 填写设备编码（必填，唯一）
   - 选择设备类型（必填）
   - 填写设备名称、型号、序列号等信息
   - 点击"保存"

3. **提交入库单**
   - 确认设备信息无误
   - 点击"提交审批"
   - 系统提示："入库单已提交，等待审批"

#### 注意事项
- ⚠️ 设备编码必须唯一，系统会自动校验
- ⚠️ 提交后设备状态变为"待入库"，此时设备**不可出库**
- ⚠️ 待入库设备会显示在设备列表中，状态标记为"待入库"

---

### 2.2 审批入库单

#### 操作路径
**库存管理** → **入库管理** → **待审批** → **审批**

#### 操作步骤

1. **查看待审批列表**
   - 筛选状态为"待审批"的入库单
   - 点击入库单号查看详情

2. **审批操作**
   - **通过**：点击"通过"按钮，填写审批意见（选填）
     - 设备状态自动变为"在库"
     - 设备可进行出库操作
   - **拒绝**：点击"拒绝"按钮，必须填写拒绝原因
     - 入库单状态变为"已拒绝"
     - 待入库设备自动删除

#### 审批权限
| 角色 | 审批权限 |
|-----|---------|
| 管理员 | ✅ 可以审批 |
| 操作员 | ❌ 不能审批 |

---

### 2.3 查看入库记录

#### 操作路径
**库存管理** → **入库管理** → **入库记录**

#### 查询条件
- 入库单号
- 供应商
- 状态（待提交/待审批/已通过/已拒绝）
- 日期范围

#### 列表字段
| 字段 | 说明 |
|-----|------|
| 入库单号 | 系统生成的唯一编号 |
| 供应商 | 设备来源供应商 |
| 设备数量 | 入库设备总数 |
| 状态 | 当前审批状态 |
| 申请人 | 创建入库单的人员 |
| 申请时间 | 提交审批的时间 |
| 审批人 | 审批通过/拒绝的人员 |
| 审批时间 | 完成审批的时间 |

## 三、设备状态说明

### 3.1 状态定义

| 状态 | 说明 | 可执行操作 |
|-----|------|-----------|
| **待入库** | 已创建，等待审批 | 编辑、删除、查看 |
| **在库** | 审批通过，可正常使用 | 出库、调拨、查看 |
| **使用中** | 已出库安装 | 维修、归还、查看 |
| **维护中** | 正在维修 | 完成维修、查看 |
| **已报废** | 生命周期结束 | 仅查看 |

### 3.2 状态流转规则

```
待入库 → 在库（审批通过）
待入库 → 已删除（审批拒绝）
在库 → 使用中（出库）
在库 → 维护中（报修）
使用中 → 在库（归还）
使用中 → 维护中（故障）
维护中 → 在库（修复完成）
维护中 → 已报废（无法修复）
```

## 四、常见问题解答

### Q1: 为什么提交入库单后设备显示"待入库"状态？

**A**: 这是新流程的设计。设备创建后需要先经过审批，审批通过后才会变为"在库"状态。待入库状态的设备不可出库，确保库存数据的准确性。

### Q2: 待入库设备可以编辑吗？

**A**: 可以。在入库单审批前，您可以编辑设备信息。审批通过后，设备信息将被锁定，如需修改请联系管理员。

### Q3: 审批拒绝后设备去哪了？

**A**: 审批拒绝后，待入库设备会自动删除，不会出现在设备列表中。您可以重新创建入库单。

### Q4: 如何查看待入库设备？

**A**: 两种方式：
1. 在"入库管理"页面查看状态为"待审批"的入库单
2. 在"设备列表"页面筛选状态为"待入库"的设备

### Q5: 历史入库的设备会受影响吗？

**A**: 不会。历史已入库的设备保持"在库"状态，不受新流程影响。

### Q6: 为什么有些设备无法出库？

**A**: 只有"在库"状态的设备才能出库。如果设备显示"待入库"，请先完成入库审批流程。

## 五、操作注意事项

### 5.1 创建入库单时
- ✅ 确保设备编码唯一，避免重复
- ✅ 准确填写设备类型，影响后续分类统计
- ✅ 检查目标货位是否有足够空间
- ✅ 确认供应商信息准确

### 5.2 审批时
- ✅ 仔细核对设备信息
- ✅ 拒绝时必须填写明确原因
- ✅ 审批通过后不可撤销

### 5.3 日常管理
- ✅ 定期清理待审批的入库单
- ✅ 关注待入库设备数量，及时审批
- ✅ 保持设备编码规范统一
