## 系统概述

仓库管理系统(WMS)是一个功能完善的仓储管理解决方案，提供设备管理、库存管理、出入库管理等核心功能。

### 系统特点

- 📦 完整的设备生命周期管理
- 📊 实时库存监控
- 🔍 强大的查询和统计功能
- 🔐 完善的权限管理
- 📱 响应式设计，支持多设备访问

### 系统要求

- **浏览器**: Chrome 90+、Edge 90+、Firefox 88+、Safari 14+
- **屏幕分辨率**: 1280x720 或更高
- **网络**: 稳定的互联网连接

## 快速开始

### 登录系统

1. 打开浏览器，访问系统地址
2. 在登录页面输入用户名和密码
3. 点击"登录"按钮

**默认账号**:
- 管理员: `admin` / `Admin@123456`
- 操作员: `operator` / `Operator@123456`
- 技术员: `technician` / `Technician@123456`

### 系统主界面

登录成功后，进入系统主界面，包含以下区域：

- **顶部导航栏**: 显示系统名称、用户信息、退出登录
- **左侧菜单栏**: 显示所有功能模块
- **主内容区**: 显示当前功能页面
- **底部状态栏**: 显示系统状态信息

## 设备管理

### 设备列表

**路径**: 设备管理 > 设备列表

**功能说明**:
- 查看所有设备信息
- 支持按条件筛选设备
- 支持分页浏览
- 支持导出设备列表

**操作步骤**:
1. 点击左侧菜单"设备管理" > "设备列表"
2. 在列表页面可以查看所有设备信息
3. 使用筛选条件过滤设备
4. 点击"导出"按钮导出设备列表

**筛选条件**:
- 设备编码
- 设备名称
- 设备状态
- 所属仓库
- 设备类型

### 新增设备

**操作步骤**:
1. 在设备列表页面，点击"新增设备"按钮
2. 填写设备信息：
   - 设备编码（必填）
   - 设备名称（必填）
   - 设备类型（必填）
   - 所属仓库（必填）
   - 存放货位（选填）
   - 设备状态（必填）
   - 购买日期（选填）
   - 设备价格（选填）
   - 备注信息（选填）
3. 点击"保存"按钮

**注意事项**:
- 设备编码必须唯一
- 设备编码长度1-50个字符
- 设备价格必须≥0

### 编辑设备

**操作步骤**:
1. 在设备列表页面，找到要编辑的设备
2. 点击操作列的"编辑"按钮
3. 修改设备信息
4. 点击"保存"按钮

### 删除设备

**操作步骤**:
1. 在设备列表页面，找到要删除的设备
2. 点击操作列的"删除"按钮
3. 在确认对话框中点击"确定"

**注意事项**:
- 删除操作不可恢复
- 已有出入库记录的设备不能删除

### 设备详情

**操作步骤**:
1. 在设备列表页面，点击设备编码或名称
2. 查看设备详细信息
3. 查看设备历史记录

## 库存管理

### 库存查询

**路径**: 库存管理 > 库存查询

**功能说明**:
- 查看所有库存信息
- 支持按仓库、货位、设备筛选
- 支持导出库存报表

**操作步骤**:

2. 使用筛选条件过滤库存
3. 查看库存详情
4. 点击"导出"按钮导出库存报表

### 入库管理

**路径**: 库存管理 > 入库管理

**功能说明**:
- 创建入库单
- 查看入库记录
- 入库单审核

**新增入库单步骤**:
1. 点击"新增入库单"按钮
2. 填写入库单信息：
   - 入库单号（自动生成）
   - 供应商（必填）
   - 入库仓库（必填）
   - 入库日期（必填）
3. 添加入库明细：
   - 设备编码（必填）
   - 入库数量（必填）
   - 单价（必填）
4. 点击"保存"按钮

**注意事项**:
- 入库数量必须>0
- 单价必须≥0
- 可以添加多个入库明细

### 出库管理

**路径**: 库存管理 > 出库管理

**功能说明**:
- 创建出库单
- 查看出库记录
- 出库单审核

**新增出库单步骤**:
1. 点击"新增出库单"按钮
2. 填写出库单信息：
   - 出库单号（自动生成）
   - 出库仓库（必填）
   - 出库日期（必填）
3. 添加出库明细：
   - 设备编码（必填）
   - 出库数量（必填）
4. 点击"保存"按钮

**注意事项**:
- 出库数量不能超过库存数量
- 可以添加多个出库明细

### 库存记录

## 用户管理

### 用户列表

**路径**: 系统管理 > 用户管理

**功能说明**:
- 查看所有用户信息
- 支持新增、编辑、删除用户
- 支持重置用户密码

**新增用户步骤**:
1. 点击"新增用户"按钮
2. 填写用户信息：
   - 用户名（必填）
   - 密码（必填）
   - 真实姓名（必填）
   - 电子邮箱（选填）
   - 联系电话（选填）
   - 用户角色（必填）
3. 点击"保存"按钮

**用户角色**:
- 管理员: 拥有所有权限
- 操作员: 拥有日常操作权限
- 技术员: 拥有查看和维修权限

**注意事项**:
- 用户名必须唯一
- 密码长度至少8位，包含大小写字母和数字
- 用户创建后，角色不能修改

### 重置密码

**操作步骤**:
1. 在用户列表页面，找到要重置密码的用户
2. 点击操作列的"重置密码"按钮
3. 在确认对话框中点击"确定"
4. 系统将生成新密码并显示

## 常见问题

### Q1: 忘记密码怎么办？

**A**: 请联系系统管理员重置密码。

### Q2: 设备编码重复怎么办？

**A**: 设备编码必须唯一，请检查是否已存在相同编码的设备。

### Q3: 出库数量超过库存数量怎么办？

**A**: 系统会提示库存不足，请调整出库数量或先进行入库操作。

### Q4: 如何导出数据？

**A**: 在列表页面点击"导出"按钮，选择导出格式（Excel、CSV等）。

### Q5: 系统运行缓慢怎么办？

**A**:
1. 检查网络连接是否正常
2. 清理浏览器缓存
3. 联系系统管理员检查服务器状态

### Q6: 如何联系技术支持？

**A**: 
- 邮箱: tech.support@example.com
- 电话: 400-XXX-XXXX

### Q7: 权限不足怎么办？

**A**: 请联系系统管理员申请相应权限。

### Q8: 数据丢失怎么办？

**A**: 系统有定期备份机制，请联系系统管理员恢复数据。
