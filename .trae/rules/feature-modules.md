## 1. 认证授权模块 (Auth)

### 1.1 功能描述
提供用户认证和授权功能，确保系统安全性和权限控制。

### 1.2 子功能列表
| 子功能 | 描述 | 备注 |
|-------|------|------|
| 用户登录 | 用户通过用户名和密码登录系统 | 支持验证码 |
| 用户注册 | 新用户注册系统账号 | 需管理员审核 |
| 用户登出 | 用户退出系统 | 清除会话信息 |
| 获取当前用户信息 | 获取登录用户的基本信息和权限 | |
| 刷新令牌 | 刷新用户认证令牌 | 延长会话有效期 |
| 重置密码 | 用户忘记密码时重置密码 | 需邮箱验证 |
| 验证令牌 | 验证令牌的有效性 | |

### 1.3 数据要求
| 数据项 | 类型 | 说明 |
|-------|------|------|
| username | String | 用户名，唯一标识 |
| password | String | 密码，加密存储 |
| token | String | 认证令牌 |
| refreshToken | String | 刷新令牌 |
| expiredTime | Long | 令牌过期时间 |
