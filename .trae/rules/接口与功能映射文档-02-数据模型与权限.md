## 5. 权限控制

### 5.1 角色定义

| 角色名称 | 角色编码 | 描述 |
|----------|----------|------|
| 系统管理员 | ADMIN | 拥有系统所有权限，负责系统配置和用户管理 |
| 仓库管理员 | WAREHOUSE_ADMIN | 负责仓库设备管理、出入库操作和维护记录管理 |
| 设备管理员 | DEVICE_ADMIN | 负责设备的日常维护和维修管理 |
| 普通用户 | USER | 只能查看设备信息和维护记录，无操作权限 |

### 5.2 权限控制实现

#### 5.2.1 后端权限控制

后端使用Spring Security框架实现基于角色的访问控制（RBAC），主要通过以下方式实现：

1. **URL级权限控制**：使用`@PreAuthorize`注解在控制器方法上进行权限控制
2. **方法级权限控制**：使用`@PreAuthorize`注解在服务层方法上进行权限控制
3. **数据级权限控制**：在数据访问层实现基于用户角色的数据过滤

#### 5.2.2 前端权限控制

前端使用Vue Router的导航守卫实现路由级权限控制，主要通过以下方式实现：

1. **路由懒加载**：根据用户权限动态加载路由
2. **导航守卫**：在路由跳转前检查用户是否有访问权限
3. **按钮级权限控制**：根据用户权限动态显示或隐藏操作按钮

## 6. 错误处理

### 6.1 错误码定义

错误码采用4位数字编码，分类如下：

| 错误码 | 描述 |
|--------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 204 | 无内容（删除成功） |
| 400 | 参数错误 |
| 401 | 未授权（未登录或令牌过期） |
| 403 | 禁止访问（无权限） |
| 404 | 资源不存在 |
| 405 | 方法不允许 |
| 409 | 资源冲突 |
| 422 | 参数验证失败 |
| 429 | 请求过于频繁 |
| 500 | 服务器内部错误 |
| 501 | 接口未实现 |
| 502 | 网关错误 |
| 503 | 服务不可用 |

### 6.2 业务错误码

| 错误码 | 描述 |
|--------|------|
| 1001 | 用户名或密码错误 |
| 1002 | 用户已被禁用 |
| 1003 | 用户名已存在 |
| 1004 | 邮箱已被注册 |
| 2001 | 设备不存在 |
| 2002 | 设备编码已存在 |
| 2003 | 设备状态不允许此操作 |
| 3001 | 区域不存在 |
| 3002 | 区域下存在设备，无法删除 |
| 4001 | 出入库单不存在 |
| 4002 | 出入库单状态不允许此操作 |
| 4003 | 库存不足 |
| 5001 | 权限不足 |

```json
  "code": 400,
  "data": null,
  "errors": [
    {
      "field": "字段名",
      "message": "字段错误信息"
    }
  ]
}
```

### 6.4 异常处理策略

1. **参数校验异常**：返回400错误码，并在errors数组中返回具体字段错误信息
2. **业务异常**：返回对应的业务错误码和错误信息
3. **系统异常**：返回500错误码，记录详细错误日志，返回友好错误信息
4. **权限异常**：返回403错误码，提示无权限访问
