# 权限控制规则

## 1. 角色定义

| 角色 | 角色标识 | 描述 | 权限范围 |
|------|---------|------|---------|
| 管理员 | ADMIN | 系统管理员 | 所有功能模块的所有操作权限 |
| 操作员 | OPERATOR | 普通操作员 | 仅能访问设备管理、维护管理、出入库管理、统计分析等业务模块，不能访问系统管理相关功能 |

## 2. 权限控制实现方式

### 2.1 后端权限控制
- 使用Spring Security框架实现基于角色的访问控制（RBAC）
- 通过`@PreAuthorize`注解在控制器方法上定义访问权限
- 权限表达式格式：`hasRole('ROLE_NAME')`或`hasAuthority('AUTHORITY_NAME')`

### 2.2 前端权限控制
- 基于Vue Router的路由元信息（meta）实现路由级别权限控制
- 在路由配置中通过`meta.roles`定义可访问该路由的角色列表
- 结合动态路由加载，根据用户角色动态生成可访问的路由表
- 页面组件内部通过权限指令（如`v-if="hasPermission('permission')"`）实现按钮级别的权限控制

## 4. 权限控制最佳实践

### 4.1 后端开发注意事项
1. 所有控制器方法必须添加`@PreAuthorize`注解明确权限要求
2. 避免在服务层或数据访问层添加权限控制，权限控制应集中在控制器层
3. 对于敏感操作（如删除、批量操作），应额外添加日志记录
4. 权限控制应与业务逻辑分离，便于维护和扩展

### 4.2 前端开发注意事项
1. 路由配置必须添加`meta.roles`定义可访问角色
2. 页面组件中敏感操作按钮应根据用户角色动态显示/隐藏
3. 前端权限控制仅作为辅助手段，不能替代后端权限控制
4. 定期同步前后端权限配置，确保一致性

### 4.3 权限测试要求
1. 每个API接口必须测试不同角色的访问权限
2. 验证未授权用户无法访问受限资源
3. 验证授权用户可以正常访问授权资源
4. 测试权限变更后的实时生效情况

## 5. 权限变更流程

1. 需求分析：评估权限变更的必要性和影响范围
2. 方案设计：制定权限变更方案，明确变更内容和影响
3. 开发实现：修改后端权限注解和前端权限配置
4. 测试验证：测试权限变更后的功能可用性和安全性
5. 文档更新：更新权限控制规则文档
6. 上线部署：在生产环境部署权限变更
7. 监控审计：监控权限变更后的系统运行情况，确保无异常

## 6. 权限审计

- 系统将记录所有权限相关操作的日志
- 日志内容包括：操作时间、操作人、操作类型、操作结果、影响范围
- 定期对权限日志进行审计，发现并处理异常权限操作
- 权限审计结果作为系统安全评估的重要依据

## 后端权限控制示例
```java
@RestController
@RequestMapping("/users")
public class UserController {
    
    // 仅管理员可访问
    @PreAuthorize("hasRole('ADMIN')")
    @GetMapping
    public ApiResponse getUserList() {
        // 业务逻辑
    }
    
    // 所有已登录用户可访问
    @PreAuthorize("isAuthenticated()")
    @GetMapping("/profile")
    public ApiResponse getCurrentUserProfile() {
        // 业务逻辑
    }
}
```

## 前端路由权限控制示例
```javascript
const routes = [
    {
        path: '/users',
        name: 'users',
        component: () => import('@/views/users/index.vue'),
        meta: {
            title: '用户管理',
            icon: 'user',
            roles: ['admin'] // 仅管理员可访问
        }
    },
    {
        path: '/devices',
        name: 'devices',
        component: () => import('@/views/devices/index.vue'),
        meta: {
            title: '设备管理',
            icon: 'device',
            roles: ['admin', 'operator'] // 管理员和操作员均可访问
        }
    }
]
```

## 前端按钮权限控制示例
```vue
<template>
    <div>
        <el-button type="primary" @click="addDevice">添加设备</el-button>
        <el-button type="danger" @click="deleteDevice" v-if="hasPermission('admin')">删除设备</el-button>
    </div>
</template>

<script setup>
import { useUserStore } from '@/stores/user';

const userStore = useUserStore();

const hasPermission = (role) => {
    return userStore.currentUser?.role === role;
}
</script>
